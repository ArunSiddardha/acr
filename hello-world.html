🌍 Hello World Ruby Application

Welcome to Our Ruby Hello World App!

This is a simple demonstration of a Ruby-based Hello World application integrated with Jekyll.

Features:

  • ✨ Standalone Ruby script execution
  • 🌐 Jekyll integration for web display
  • ⏰ Dynamic timestamp generation
  • 👥 Customizable greetings

Ruby Code Example:

class HelloWorld
  def initialize(name = "World")
    @name = name
  end

  def greet
    "Hello, #{@name}!"
  end
end

hello = HelloWorld.new("Ruby Developer")
puts hello.greet

Try It Out:

To run the standalone Ruby script, use the following command in your terminal:

ruby hello_world.rb
