# 📝 Note-Taking App

A beautiful, modern note-taking web application with a clean interface and essential features.

## Features

- ✨ **Create, Edit, and Delete Notes** - Full CRUD functionality
- 🔍 **Search Notes** - Quickly find notes by title or content
- 💾 **Auto-Save** - Your notes are automatically saved as you type
- 📱 **Responsive Design** - Works on desktop and mobile devices
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- 💿 **Local Storage** - All notes are saved locally in your browser
- ⚡ **Real-time Character Count** - Track your note length
- ⏰ **Timestamp Tracking** - See when notes were last updated

## How to Use

1. **Open the App**: Simply open `index.html` in your web browser
2. **Create a Note**: Click the "+ New Note" button
3. **Edit Note**: Click on any note in the sidebar to edit it
4. **Search**: Use the search box to filter notes by title or content
5. **Delete**: Click the delete button when viewing a note

## Technologies Used

- HTML5
- CSS3 (with modern gradients and animations)
- Vanilla JavaScript (ES6+)
- Local Storage API

## Installation

No installation required! Just open `index.html` in any modern web browser.

If you want to run it on a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## Features in Detail

### Auto-Save
Notes are automatically saved 500ms after you stop typing, so you never lose your work.

### Search Functionality
The search feature filters notes in real-time as you type, searching both titles and content.

### Local Storage
All notes are stored in your browser's local storage, so they persist between sessions.

### Responsive Design
The app adapts to different screen sizes for a great experience on any device.
