# Alumni

## Todo App

A lightweight, accessible Todo app lives at `todo/index.html`.

- Add, edit (double‑click), delete, toggle complete
- Filters: All / Active / Completed
- Bulk: Toggle all, Clear completed
- Persisted locally via `localStorage`

Open locally with any static server, e.g.:

```sh
python3 -m http.server 4000
# then navigate to http://localhost:4000/todo/
```
